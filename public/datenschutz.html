Datenschutz

Kurzfassung: MIRASHOT speichert nichts, trackt niemanden und setzt keine Cookies. Deine Screenshots entstehen und werden bearbeitet, wo sie hingehören: in deinem Browser.

Grundsatz: keine Speicherung, kein Tracking

  • Keine Cookies, kein LocalStorage mit Nutzerinhalten, keine Sessions, keine Nutzerkonten.
  • Kein Tracking, keine Analytics, keine Werbe-Netzwerke.
  • Keine externen Ressourcen: Diese Seite lädt keine Schriftarten, Skripte oder Bilder von Dritt-Anbietern — der Browser sendet dadurch keine Anfragen an Dritte.
  • Keine Persistenz: Screenshots werden niemals auf dem Server gespeichert. Nach dem Streaming an deinen Browser sind sie verworfen. Ein Neustart des Servers löscht zwangsläufig alles, was es ohnehin nie gab.

Tab „Webseite ablichten“

Wenn du eine Adresse abschickst, ruft der Server sie einmalig mit einem Headless-Browser (Chromium) ab und streamt das PNG direkt an dich zurück.

  • Die angefragte Adresse wird nicht gespeichert und nicht in Logs geschrieben (der Access-Log des Webservers zeichnet nur den Pfad /api/shot ohne Abfrage-Parameter auf).
  • Zur Missbrauchs-Abwehr (SSRF) wird die Ziel-Adresse technisch geprüft: Nur öffentlich routbare http/https-Ziele sind erlaubt; Zugriffe auf interne Netze werden abgelehnt.
  • Von der besuchten Zielseite gehen keine Cookies oder Logins des Betreibers ab — der Abruf erfolgt mit einem leeren, neu erzeugten Browser-Profil.

Tab „Bildschirm“

Die Bildschirmaufnahme läuft vollständig in deinem Browser (getDisplayMedia). Es werden keinerlei Daten an den Server übertragen. Der Server erfährt nicht einmal, dass du diesen Tab benutzt.

Annotation-Editor

Alle Bearbeitungsschritte (Zeichnen, Texte, Unschärfe, Pixelation, Undo/Redo, Download) geschehen lokal im Browser. Es existiert kein Upload-Pfad für deine Bilder — außer der ausdrücklichen KI-Nutzung (nächster Abschnitt).

KI-Features (nur auf Klick)

Wenn du eine KI-Funktion nutzt („KI-Analyse“, „Sensible Daten pixeln“, „Alt-Text kopieren“), wird das Bild zur Analyse an einen externen KI-Dienst gesendet. Das geschieht ausschließlich auf deinen ausdrücklichen Klick, einmalig pro Klick und ohne Speicherung auf MIRASHOT-Seite.

  • Übertragen wird eine reduzierte Kopie des Bildes (max. 1600 px Kante, PNG) an den im Betrieb konfigurierten KI-Endpoint (OpenAI-kompatible Schnittstelle, z.B. OpenRouter oder Z.ai).
  • Die weitere Verarbeitung dort richtet sich nach der Datenschutzerklärung des jeweiligen Anbieters. Der Serverbetreiber kann diese Zusicherung für den Drittdienst nicht beeinflussen.
  • Wer keine KI nutzen will, lässt die entsprechend gekennzeichneten Buttons einfach unberührt — alle übrigen Funktionen arbeiten dann garantiert ohne jede Übertragung.
  • Ist kein KI-Dienst konfiguriert, zeigen die KI-Buttons einen entsprechenden Hinweis und es wird nichts gesendet.

Server-Logs

Der Webserver führt ein technisches Zugriffs-Protokoll (Pfad, Statuscode, Zeitpunkt, ohne Abfrage-Parameter und damit ohne deine eingegebene Adresse). Es dient ausschließlich der Fehlerdiagnose und dem Missbrauchsschutz und enthält keine Nutzerinhalte.

Self-Hosting

MIRASHOT ist freie Software (MIT) und kann selbst gehostet werden — dann gilt deine eigene Infrastruktur und Konfiguration, insbesondere für den KI-Endpoint. Siehe README im Repository.
